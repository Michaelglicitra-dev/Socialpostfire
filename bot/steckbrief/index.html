Kunde Kanäle

Ein Post geht an genau einen Kanal, und die Kanäle wechseln sich über die Woche ab. So ist jedes Bild einzigartig und hat immer das richtige Format. Kanäle ohne ID werden übersprungen.

Wochenplan: welcher Kanal an welchem Tag
Themenplan: worüber an welchem Tag gepostet wird

Kunde Hashtags

Basis-Tags je Thema. Der Bot ergänzt pro Post weitere passende. Mit Komma oder Leerzeichen trennen, das Rautezeichen setzt sich automatisch.

Du n8n-Einrichtung
